### 🚀 What I'm Building & Exploring

**🏦 RIA Lab — Learning an Industry by Building**

An independent, synthetic wealth-advisory sandbox I'm building to understand how financial advisors operate and explore opportunities for better software.

Rather than jumping straight into building a solution for an industry I was unfamiliar with, I wanted to understand the workflows first.

RIA Lab models fictional advisors, client households, meetings, tasks, and operational interactions, creating a small environment for learning and product experimentation.

- **Focus:** Domain modeling, full-stack engineering, workflow automation, explainable decision-making, product discovery
- **Stack:** Next.js, TypeScript, React, Tailwind CSS
- **Product experiment:** *Savvy Pulse*, a concept exploring how contextual recommendations could help advisors discover useful software capabilities and reach value faster

The long-term idea is simple: **understand the problem, build a small working solution, test the assumptions, and learn from feedback.**

*Independent educational project using synthetic data. Not affiliated with Savvy Wealth. No financial advice.*

A full-stack AI-assisted learning platform exploring how students can use active recall, retrieval practice, confidence tracking, and personalized study sessions to learn more effectively.

- React, TypeScript, Supabase/PostgreSQL, LLM APIs
- Exploring structured AI outputs, learning analytics, and measurable outcomes
- Focused on building useful learning workflows rather than adding AI for its own sake
